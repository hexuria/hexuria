# Hexuria

Public landing page for the **Durable Agent Toolchain**.

Hexuria is the infrastructure. The Durable Agent Toolchain is the category. Persistent AI coworkers are the outcome.

> Agents shouldn't just use computers.
> They should build their own.

Hexuria is building the durable toolchain that lets AI workers acquire, verify, install, permission, execute, update and replace their own software without rebuilding their entire computer.

Infrastructure for persistent AI coworkers.

- Site: [index.html](index.html) (also served from GitHub Pages when enabled)
- Org: https://github.com/hexuria
- Harness: https://github.com/hexuria/opengrok-server

This repository is the page. The software lives in the other repositories linked from it. The toolchain is not production-complete.
